# AITrainerServer — QA Portfolio

## О проекте

Учебный проект по тестированию backend API приложения AiTrainerServer. Цель проекта — продемонстрировать навыки ручного тестирования REST API, составления тестовой документации, работы с Postman и проверки данных в PostgreSQL.

**Исходный проект:** [AITrainerServer](https://github.com/RMaximI/AITrainerServer)

## Содержание проекта

* `test_cases_aitrsiner_server.json` - тест-кейсы для проверки API.
* `postman_collection_aitrainer.json` - коллекция запросов Postman.
* `sql/sql_data_validation_aitrainer.sql` - шаблоны SQL-проверок данных после API-запросов.

## Используемые инструменты

* **Postman** - отправка HTTP-запросов и проверка ответов API.
* **PostgreSQL** - проверка данных в базе.
* **SQL** - поиск записей, проверка дубликатов и сверка данных.
* **Git и GitHub** - хранение и версионирование тестовой документации.

## Цель проекта

Продемонстрировать практические навыки Junior QA Engineer:

* ручное тестирование API;
* составление тест-кейсов;
* работа с Postman;
* базовые SQL-запросы и проверка данных;
* анализ поведения приложения и документирование результатов тестирования.
